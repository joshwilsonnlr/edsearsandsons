# Ed Sears & Son Auto Repair — Premium Website

Completely redesigned, premium 3D automotive repair website for **Ed Sears & Son Auto Repair** (Ballston Spa, NY).

**Live demo:** [https://joshwilsonnlr.github.io/edsearsandsons/](https://joshwilsonnlr.github.io/edsearsandsons/)  
**Original business site:** [https://edsearsandsons.com/](https://edsearsandsons.com/)

## Features

- Dark, sophisticated automotive aesthetic with metallic accents
- Full-screen cinematic hero with Three.js abstract vehicle scene + particles
- GSAP + ScrollTrigger scroll-triggered animations
- Interactive 3D-style service cards with hover depth
- Real customer reviews carousel (sourced from original site)
- Recently serviced vehicles carousel
- Interactive service experience tabs
- Foreign / Domestic vehicle brand grids
- Sticky responsive navigation with mobile hamburger menu
- Working appointment CTAs linking to the original booking system
- Click-to-call phone numbers
- Google Maps embed
- LocalBusiness / AutoRepair schema markup
- SEO-optimized meta, Open Graph, semantic HTML
- Full mobile-first responsiveness
- `prefers-reduced-motion` support
- Accessible focus states and skip link

## Tech Stack

- HTML5
- Modern CSS (custom properties, grid, flexbox, glassmorphism)
- Vanilla JavaScript
- GSAP 3 + ScrollTrigger (CDN)
- Three.js r128 (lightweight hero scene)

